# Contributing

First of all, thank you for considering contributing to this project! ❤️

**Everyone is welcome to contribute** — whether you're fixing a bug, improving documentation, adding a feature, reporting an issue, or suggesting an idea.

## How to Contribute

1. **Fork** this repository.
2. **Clone** your fork locally.
3. Create a new branch for your changes:

   ```bash
   git checkout -b feature/my-feature
   ```

4. Make your changes.
5. Test your changes to make sure everything works correctly.
6. Commit your changes:

   ```bash
   git add .
   git commit -m "Add my feature"
   ```

7. Push your branch:

   ```bash
   git push origin feature/my-feature
   ```

8. Open a **Pull Request** against the `main` branch.

## What You Can Contribute

You can contribute in many ways:

* 🐛 Fix bugs
* ✨ Add new features
* ⚡ Improve performance
* 📚 Improve documentation
* 🧪 Add or improve tests
* 🎨 Improve examples
* 💡 Suggest new ideas
* 🔧 Improve code quality
* 🌍 Add translations

## Before Submitting a Pull Request

Please make sure:

* Your code follows the project's existing style.
* Your changes don't break existing functionality.
* You have tested your changes.
* Your Pull Request clearly explains what you changed and why.
* You update documentation when necessary.

## Reporting Issues

If you find a bug or have a feature request, please open an **Issue** and provide as much information as possible.

For bugs, include:

* What happened
* What you expected to happen
* Steps to reproduce the problem
* Your operating system
* Package/project version
* Relevant error messages or logs

## Pull Requests

Please keep Pull Requests focused on a single change whenever possible.

Small, clear Pull Requests are easier to review and merge.

Maintainers may request changes before a Pull Request is merged. Please don't take this personally — the goal is to keep the project stable and maintainable.

## Code of Conduct

Please be respectful and welcoming to other contributors.

Harassment, discrimination, spam, or intentionally harmful contributions are not acceptable.

## Thank You ❤️

Every contribution matters, no matter how small.

Thank you for helping make this project better! 🚀
